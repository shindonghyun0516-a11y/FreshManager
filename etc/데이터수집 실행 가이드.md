# 데이터 수집 실행 가이드 (비개발자용)

*이 문서는 요구사항 정의서 v0.4의 내용을 실제로 손으로 따라 할 수 있는 단계로 풀어쓴 것이다. 어려운 용어(FR-0, request_id 등)는 여기서 안 나온다 — 실행에만 집중한다.*

---

## 전체 그림 (5단계)

```
1단계. 열쇠 받기         (웹사이트 클릭만, 코딩 없음)
        ↓
2단계. 눈으로 확인하기     (브라우저 주소창에 붙여넣기, 코딩 없음)
        ↓
3단계. 자동 수집 만들기    (제가 써드리는 코드 복붙, 아주 약간의 설정)
        ↓
4단계. 며칠에 한 번 들여다보기 (5분이면 충분)
        ↓
5단계. 4~5주 후 같이 분석하기
```

지금 당장 하셔야 할 건 1단계뿐이다. 나머지는 그 다음에 하나씩.

---

## 1단계. API 열쇠(인증키) 받기 — 오늘 할 일, 약 10분

"API 열쇠"란, 서울시 데이터를 가져다 쓸 수 있게 해주는 비밀번호 같은 것이다.

1. **[data.seoul.go.kr](https://data.seoul.go.kr) 접속**
2. 우측 상단 **회원가입** → 서울시 통합회원으로 가입 (이미 서울시 사이트 계정 있으면 로그인만)
3. 상단 메뉴에서 **이용안내 → Open API 소개** 클릭
4. **일반 인증키 신청** 버튼 클릭 (※ "실시간 지하철" 전용 키가 아니라 **일반** 인증키를 선택하는 게 중요하다)
5. 신청 화면에 아래 내용을 그대로 복사해서 붙여넣는다.

   - **활용명**: `프레시매니저 유동판매 추천 서비스 데이터 타당성 PoC`
   - **활용 목적**: `서울시 실시간 도시데이터의 여의도 인구·혼잡도·미래예측·상권현황·날씨 데이터를 수집하여 시간대별 패턴과 예측 활용 가능성을 분석하기 위한 비상업적 개인 PoC`

6. 제출하면 보통 **바로 발급**되거나 몇 시간 안에 이메일로 온다.
7. 발급된 열쇠(긴 영문·숫자 조합)를 **메모장 같은 곳에 저장**해둔다.

**절대 하지 말 것**: 이 열쇠를 카톡, 블로그, 스크린샷, 저에게 보내는 메시지 등 어디에도 남기지 않는다. 나중에 코드에 넣을 때는 제가 안전하게 넣는 방법을 알려드린다.

✅ **이 단계 완료 신호**: 메모장에 긴 영문·숫자 열쇠가 저장돼 있으면 끝.

---

## 2단계. 진짜로 데이터가 오는지 눈으로 확인하기 — 약 5분

코딩 없이, 그냥 인터넷 주소창에 주소를 입력해서 확인하는 단계다.

1. 아래 형태의 주소를 만든다 (실제로는 제가 정확한 주소를 다음 턴에 같이 만들어드릴 수 있다 — 우선 개념만):
   ```
   http://openapi.seoul.go.kr:8088/[발급받은열쇠]/json/citydata_ppltn/1/5/여의도
   ```
2. 이걸 크롬이나 엣지 주소창에 붙여넣고 엔터.
3. 화면에 알 수 없는 글자 뭉치(JSON이라고 부르는 형식)가 쭉 나오면 **성공**이다. 인구 수, 혼잡도 같은 단어가 영어로 섞여 보이면 잘 되고 있는 것이다.
4. 에러 메시지가 나오면 캡처해서 저에게 보여주시면 바로 원인을 봐드린다.

✅ **이 단계 완료 신호**: 브라우저에 여의도 관련 데이터 글자뭉치가 실제로 보임.

---

## 3단계. 자동으로 계속 모으는 시스템 만들기 — 코드는 제가 씀

5주 동안 5~10분마다 계속 데이터를 받아야 하는데, 사람이 계속 붙어서 주소를 입력할 수는 없다. 그래서 **자동으로 알아서 돌아가는 시스템**이 필요하다.

**추천 방법: 구글 스프레드시트 + 자동 스크립트**

이유는 간단하다.
- 컴퓨터를 따로 켜둘 필요 없음 (구글이 대신 실행해줌)
- 무료
- 데이터가 눈에 보이는 표 형태로 저절로 쌓임 (엑셀처럼 보임)
- 설치할 프로그램 없음, 브라우저만 있으면 됨

이 단계에서 하실 일은:
1. 구글 스프레드시트를 하나 새로 만든다 (구글 계정만 있으면 됨)
2. 메뉴에서 **확장 프로그램 → Apps Script** 클릭 (코드를 넣는 창이 열림)
3. 제가 써드리는 코드를 통째로 복사해서 그 창에 붙여넣는다
4. 열쇠(1단계에서 받은 것)를 지정된 한 줄에만 붙여넣는다
5. "트리거"라는 메뉴에서 "5분마다 실행" 같은 걸 설정한다 (이것도 제가 화면 클릭 순서대로 알려드림)

**이 부분은 1단계·2단계가 끝나신 다음에, 다음 대화에서 실제 코드와 함께 화면 클릭 순서를 하나하나 알려드리겠습니다.** 지금은 "아, 이런 방식으로 하는구나" 정도만 알고 계시면 된다.

---

## 4단계. 며칠에 한 번 5분씩 들여다보기

- 구글 스프레드시트를 열어서 새 줄이 계속 쌓이고 있는지 확인
- 빈 칸이 너무 많거나, 며칠째 안 쌓이고 있으면 캡처해서 저에게 보여주기
- 그 외엔 딱히 할 일 없음 — 그냥 잘 도는지 가끔 확인만

---

## 5단계. 4~5주 후, 다시 저와 함께 분석

- 쌓인 스프레드시트를 CSV 파일로 내보내기 (구글 시트 메뉴에 있음)
- 그 파일을 저에게 업로드
- 예측이 맞았는지, 사람 많은 시간대가 따로 있었는지 같이 분석 (Gate A·B 판정)
