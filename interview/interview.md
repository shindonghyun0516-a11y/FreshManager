# Gate C 인터뷰 설계 — 사용자 문제 타당성 검증

*근거: 리서치 문서(2026-07-16 공유) + 외부 검토(같은 날, 생존자 편향 지적) + 본인의 실행 가능성 검토. 인용 논문(Palinkas et al., 2015, 목적표집)은 직접 원문 확인 완료.*

---

## 1. 조사 목적

통계적 대표성 조사가 아니라, 다음 문제 가설의 존재 여부와 발생 조건을 탐색하는 질적 조사다.

> 프레시매니저는 정기배송 이후 제한된 시간과 담당구역 안에서 유동판매 위치와 시간을 결정할 때 어려움을 겪으며, 데이터 기반 정보가 이 판단을 지원할 수 있다.

기존 웹 리서치는 폐기하지 않되, "고충 확정 자료"가 아니라 "인터뷰 가설·질문 발굴용 선행 탐색자료"로 재분류한다.

## 2. 왜 표본 설계를 다시 짰는가

기존 웹 리서치(여의도·공덕 사례 등)와 추가로 확인된 사례(판매왕·명예의 전당 수상자들)는 전부 **고성과·장기근속자**다. 이 프로젝트가 도우려는 대상은 정확히 반대편 — 위치 선정에 어려움을 겪는 사람 — 인데, 지금까지의 근거는 이미 노하우를 확립한 사람들에게서만 나왔다. hy 영업점이나 공식 채널을 통한 섭외는 구조적으로 "소개하고 싶은 사람"만 걸러낼 가능성이 높으므로, 표집 방법 자체를 바꿔야 한다.

## 3. 표집 방법

네 가지를 결합한다(Palinkas et al., 2015의 목적표집 유형 중 발췌).

- **층화 목적표집**: 상권·성과 수준·경력·활동 상태별로 참여자를 나눈다.
- **최대변이표집**: 서로 다른 조건의 참여자를 포함해 공통 문제와 차이를 찾는다.
- **부정사례표집(disconfirming case)**: "위치 선정에 문제없다"고 답할 가능성이 높은 고성과자를 의도적으로 포함해, 가설을 반증할 기회를 준다.
- **이탈사례표집**: 현재 종사자만이 아니라 중단·퇴직 경험자를 포함한다.

## 4. 표본 구성 (총 16명)

| 그룹 | 인원 | 선정 기준 |
|---|---|---|
| 활동 중 어려움 경험 | 5명 | 최근 판매 정체·감소, 위치 선정 불확실성, 무판매 대기 경험 |
| 평균·안정 활동 | 4명 | 판매·활동 패턴이 비교적 안정적 |
| 고성과·노하우 보유 | 2명 | 고정고객·고정 스폿 또는 높은 판매성과 (부정사례 표집) |
| 신규 진입 | 2명 | 활동 6개월 이하 |
| 중단·휴업·이탈 경험 | 3명 | 최근 2년 내 중단 또는 이탈 고려 경험 |

**상권별 최소 구성**: 오피스 상권 10명 이상(어려움 4·평균 2·고성과 1·신규 1·이탈 2), 오피스·주거 혼합 3명, 주거 3명.

추가 분산: 활동기간(6개월 이하/1~5년/10년 이상), 연령대, 정기배송·유동판매 비중, 활동시간대, 코코 이용 여부, 판매 흐름(증가/유지/감소), 지속 의향. **성별은 모집 제한조건으로 쓰지 않고 실제 구성만 기록한다** — hy 공식 모집 페이지도 성별을 명시하지 않으므로(확인됨), 여성으로 한정할 근거가 없다.

## 5. 모집 시 금지사항

- 영업점 추천 우수 판매원만 모집하지 않는다
- 판매왕·장기근속자만 모집하지 않는다
- 현재 활동자만 모집하지 않는다
- 정확한 월수입 공개를 참여 조건으로 요구하지 않는다
- "판매가 낮은 사람" 같은 낙인성 표현을 쓰지 않는다
- 서비스가 필요하다는 답변을 유도하지 않는다

## 6. 이탈자·저성과자 모집 채널 (신규 추가)

기존 hy 공식 채널(영업점 소개, 대회·행사)로는 구조적으로 이 두 그룹에 닿기 어렵다. 대안 채널을 병행한다.

- **직장인 익명 커뮤니티(블라인드 등)**: 실적·업무강도 관련 솔직한 글이 올라오는 걸 이전 검색에서 확인함. 댓글로 조사 참여를 요청하는 방식 검토
- **지역 커뮤니티·맘카페**: 특정 아파트·지역을 담당하는 매니저가 활동하는 걸 확인했으므로(변미숙 매니저 사례 등), 해당 지역 커뮤니티에 "이전 담당 매니저가 바뀌었다"는 식의 후기가 있을 수 있음
- **직접 현장 접촉**: 영업점을 거치지 않고 활동 중인 매니저에게 직접 말을 걸어 소개를 부탁하는 스노우볼 방식(단, 이 경우도 우수 사례로 편향될 수 있어 보조 수단으로만 사용)

## 7. 사전 스크리너 (수입 대신 행동 지표로 분류)

정확한 매출·수입을 직접 묻지 않고, 다음 행동·변화 지표로 성과 수준을 내부 분류한다.

| 질문 | 분류 목적 |
|---|---|
| 최근 3개월 판매 흐름은 증가·유지·감소 중 어디에 가까운가 | 성과 추세 |
| 유동판매를 일주일에 몇 번 하는가 | 활동 빈도 |
| 장소를 정할 때 확신이 없는 경우가 얼마나 자주 있는가 | 문제 경험 |
| 한 장소에서 기다렸지만 거의 팔지 못한 경험이 얼마나 자주 있는가 | 대기 손실 |
| 유동판매 장소를 자주 바꾸는가 | 탐색 행동 |
| 남은 제품 때문에 고민한 적이 있는가 | 재고 부담 |
| 활동에 전반적으로 얼마나 만족하는가 | 만족도 |
| 향후 1년 안에 계속 활동할 의향이 있는가 | 이탈 위험 |
| 활동 기간, 담당구역 유형(오피스/주거/혼합) | 기본 분류 |

## 8. 핵심 인터뷰 질문 (행동 → 실패사례 → 솔루션 순, 보강됨)

처음부터 판단·솔루션을 물으면 긍정 응답을 유도할 위험이 있어, 사실 확인 → 실패 경험 → 솔루션 판단 순으로 재구성했다.

**먼저 행동을 질문**
1. 어제 정기배송이 끝난 시각은 언제였습니까?
2. 그다음 실제로 어디로 이동했습니까?
3. 그 장소를 선택한 이유는 무엇입니까?
4. 얼마나 머물렀고 판매 결과는 어땠습니까?

**다음으로 실패사례를 질문**
5. 최근 가장 잘못 골랐다고 느낀 장소는 어디였습니까?
6. 언제 잘못된 선택이라는 것을 알았습니까?
7. 그때 다른 장소로 이동하지 않은 이유는 무엇입니까?

**마지막에 솔루션을 질문**
8. 혼잡정보가 있었다면 판단이 달라졌습니까?
9. 몇 분 전에 받아야 행동할 수 있습니까?
10. 경험과 데이터가 다르면 어떤 근거가 있어야 데이터를 믿겠습니까?

**보충 질문** (위 10개로 못 다루는 주제 — 시간이 허락하는 대로 추가하되, 첫 번째는 생략하지 않는다)
- **사람이 많아도 판매가 잘 안 되는 장소가 있는가 — 핵심 검증 질문.** 공개자료 매트릭스에서 세 후보 전원 공백으로 확인된 항목이라, 위 10개를 다 물은 뒤에도 시간이 부족하면 이 질문을 최우선으로 넣는다
- 위치와 단골고객 중 실제 수입에 더 중요한 것은 무엇인가
- 날씨·요일·행사에 따라 위치를 바꾸는가
- 남은 재고가 위치·시간 선택에 영향을 주는가
- 담당구역 안에서 자유롭게 이동할 수 있는가

**중단·이탈 경험자 추가 질문**: 중단·이탈 이유 / 기대와 실제의 차이 / 위치·시간 판단이 이탈 결정에 영향을 줬는지 / 데이터·도구가 있었다면 계속했을지 / **"위치추천 서비스가 있었다면 그만두지 않았을 것 같은가?"**(대부분 "아니다"라고 답하면, 이 프로젝트가 해결하려는 문제가 핵심 고충이 아닐 수 있음을 뜻함)

**고성과자 추가 질문(부정사례 확인용)**: 데이터 없이도 좋은 장소를 어떻게 아는지 / 신규 시절 시행착오 / 노하우를 타인에게 가르칠 수 있는지 / 실시간 유동인구 정보가 본인 판단을 바꿀 수 있는지. 답이 "좋은 장소는 이미 정해져 있고 유동인구보다 고객관계·상품구성이 중요하다"라면, 유동인구 예측 중심 가설이 약해지고 재고·인수인계·노하우 자산화 방향이 더 유효할 수 있다.

## 9. 분석 원칙

- 고성과자 의견을 전체의 의견으로 일반화하지 않는다
- 반대·예외 사례도 반드시 기록한다
- "서비스가 필요 없다"는 응답을 실패한 인터뷰로 취급하지 않는다
- 위치 문제가 아닌 다른 핵심 원인이 발견되면 문제 정의를 수정한다
- 근거 등급을 세 단계로 구분해 기록한다: 공개사례에서 관찰됨 / 복수 사례에서 반복됨 / 사용자 조사로 확인됨

## 10. Gate C 통과·재검토 기준

**통과 검토**: 위치·시간 선정에 실제 어려움 존재 / 잘못된 대기·이동으로 시간 손실 발생 / 판단을 보완할 정보 부족 / 담당구역 내 이동 재량 존재 / 데이터 제공 시 행동을 바꿀 가능성 존재 — 이 다섯이 반복적으로 확인될 때.

**재검토**: 대부분 이미 고정 스폿·노하우 보유 / 유동인구보다 정기고객·상품·재고가 압도적으로 중요 / 구역·일정 때문에 이동 불가 / 위치 선택이 판매성과에 거의 영향 없음 / 추천정보보다 다른 문제 해결이 우선 — 이 중 다수가 확인되면 제품 가설 자체를 재검토.

## 11. 실행 순서 (1인 운영자 기준, 신규 추가)

16명을 한 번에 맞추려 하지 않는다. 정보가 가장 부족하고 확보가 어려운 그룹부터 우선한다.

1. **1순위(8명)**: 어려움 경험 5명 + 중단·이탈 경험 3명 — 커뮤니티·지역 채널 활용, 시간이 가장 오래 걸릴 그룹이므로 가장 먼저 착수
2. **2순위(4명)**: 평균·안정 활동 — 비교적 접촉이 수월
3. **3순위(4명)**: 고성과 2명(부정사례 확인용) + 신규 진입 2명 — 공식 채널로도 비교적 쉽게 확보 가능하므로 마지막에 채워도 무방

이 순서는 Phase 2(PoC 데이터 수집) 진행과 병행 가능하다 — 데이터 파이프라인이 도는 4~5주 동안 위 순서로 인터뷰를 채워나가면 된다.
