**날짜**: 2026-07-14
**프로젝트명**: 프레시매니저(야쿠르트 판매원) 유동판매 위치·시간 추천 서비스 — PoC 단계

**세션 목적**: 서비스 기획 메타 프롬프트 및 실행플랜 문서 검토, 핵심 사실관계 검증, PoC 범위 확정

## 1. 프로젝트 한 줄 정의 (오늘 확정된 최종본)

> 프레시매니저(야쿠르트 판매원)는 정기배송을 마친 뒤 담당구역 내에서 유동판매를 진행하는 상황에서, 경험에만 의존해 노상판매 위치와 시간을 정하다 보니 유동인구가 많은 기회를 놓치는 문제를 겪고 있다. 이는 위치·시간대별 유동인구 정보 부재 때문에 발생하며, 서비스는 담당구역 내 유동인구 예측 데이터를 통해 같은 노동시간 대비 판매기회(현장구매) 증가를 개선한다.

이 정의는 세션 처음부터 나온 게 아니라, 아래 흐름을 거쳐 오늘 안에 수렴됐다.

---

## 2. 오늘의 의사결정 흐름 (시간순)

1. **입력 자료 검토**: "위치·시간 기반 현장 판매 최적화 서비스 기획" 메타 프롬프트(질문증강~로드맵 17단계, 25개 섹션)와, 별도로 받은 "실행플랜 문서"(Phase 0~8 + 12주 로드맵 + Go/No-Go 게이트 + 예시 2건)를 검토 대상으로 확정.
2. **메타 프롬프트 구조 검토**: PM/PO 관점에서 강점과 공백을 분리.
   - 강점: "확인된 사실/합리적 가설/추가 검증 필요" 3분류 강제, CCTV 필수 전제 배제, "유동인구 증가 ≠ 판매 증가"를 4회 이상 반복 강조, 규칙기반 MVP 우선.
   - 공백: 25번 "현재 입력 정보" 섹션이 전부 공란이라 실행 시 결과물 대부분이 "질문 리스트"가 될 수밖에 없는 구조, 알림 시점(30분/1h/3h/6h/전날)은 데스크 분석만으로 결정 불가.
3. **실행플랜 문서 사실검증 1차**: 문서에 인용된 공공데이터 수치·법 조항을 실제로 검색해 대조.
4. **실행플랜 문서 사실검증 2차**: 자치구 참여 여부, 센서 설치 위치 공개 여부를 추가 검증.
5. **고용형태별 위치정보 법리 확인**: "야쿠르트 판매원"이 이미 특수형태근로종사자(특고) 예시 직업으로 지정돼 있음을 확인.
6. **방향 재조정 (본인)**: 특고 이슈가 핵심이 아니라, "야쿠르트 판매 아주머니들이 위치 선정을 못해 매출이 낮다"는 문제 개선이 진짜 목적임을 명확히 함.
7. **프레시매니저 실제 업무구조 확인**: 정기배송(고정 담당구역) + 유동판매(코코 카트, 배송 후 노상판매) 겸업 구조, 개인사업자 계약 + 판매량 비례 수수료 확인.
8. **핵심 서비스 행동 확정 (본인 선택)**: "정기배송을 마친 후 유동판매 위치·시간 추천" — 배송 순서 자체의 최적화가 아님.
9. **데이터 해상도 문제 발견**: 지금까지 검증한 공공데이터(서울 실시간 도시데이터, S-DoT)가 랜드마크/핫스팟 중심이라 주거구역(골목·주택가)까지 커버하는지 불확실 → 대안으로 서울 생활인구(집계구 단위) 확인.
10. **MVP 범위 결정 (본인)**: 거주구역까지는 지금 커버할 수 없으니, 최소 MVP는 오피스 상권형 담당구역으로 한정.
11. **사업 추진 방식 확인**: hy 공식 제휴 여부를 질문 → **비제휴, PoC 단계**이며 제휴 제안은 추후로 확정.
12. **PoC 범위 설계**: 지금 검증 가능한 가설과 불가능한 가설을 구분하고, 여의도역을 1차 타겟 후보로 제안.
13. **확장 검토 후 제외 (본인 확인)**: 전자담배 판촉 인력을 같은 PoC 트랙에 포함하는 방안을 검토했으나, 데이터 문제(흡연시설 데이터 커버리지 불완전 + 공간단위 불일치)와 법적 문제(국민건강증진법 제9조의4 — 담배 광고·판촉은 원칙적으로 지정소매인 영업소 내부로 제한)로 제외. **프레시매니저(야쿠르트) 단일 트랙으로 확정.**

| 대상 상품 | 야쿠르트/hy 제품 |
| 핵심 사용자 | 프레시매니저 (개인사업자, 담당구역이 **오피스 상권형**인 경우로 한정) |
| 서비스 핵심 행동 | 정기배송 완료 후, 담당구역 내 유동판매(노상판매) 위치·시간 추천 |
| 사업 추진 방식 | hy 비제휴, **PoC 단계** (제휴 제안은 PoC 결과를 근거로 추후 진행) |
| 지역 범위 | 거주구역 제외, 오피스 상권 담당구역 우선 |
| PoC 1차 타겟 후보 | 여의도역 (실시간 도시데이터 포함 가능성 高 + 흡연부스 등 노상판매 후보지가 실제 좌표로 확인됨) |

### PoC 단계에서 검증 가능한 가설 vs 불가능한 가설

| 가설 | PoC(공개데이터만) 검증 가능 여부 |
|---|---|
| 데이터 가설(공공데이터로 시간대별 유동인구 설명 가능) | 가능 |
| 예측 가설(과거 데이터+외부요인으로 미래 예측 가능) | 가능 |
| 사용자 가설(판매원이 추천을 유용하게 느끼는지) | 부분 가능(비공식 인터뷰 정도) |
| 성과 가설(추천이 실제 매출/접촉수를 늘리는지) | **불가능** — 실제 판매실적 데이터 필요, hy 제휴/현장실증 이후 과제 |
| 운영 가설(추천받으면 실제 이동하는지) | **불가능** |
| 알림 가설(최적 알림 시점) | **불가능** |

→ **이번 PoC의 성공 기준은 "예측 정확도/설명력"이지 "매출 증가"가 아니며**, PoC 결과 자체를 이후 hy 제안의 근거자료로 포지셔닝하기로 함.

**공식 명칭 정리(외부 검토 반영)**: "서비스 PoC"라고 부르면 사용자 행동·판매성과까지 검증한 것으로 오해될 수 있어, **"프레시매니저 유동판매 추천 서비스 — 데이터 타당성 PoC"**로 명칭을 구체화함.

### PoC 성공 기준 세분화(외부 검토 반영, 예측 정확도 한 줄보다 정교화)

| 검증 영역 | 확인할 질문 |
|---|---|
| 데이터 커버리지 | 여의도 오피스 상권을 대표할 수 있는 공간 영역인가 |
| 수집 안정성 | API를 누락 없이 지속적으로 수집할 수 있는가 |
| 시간 해상도 | 판매 위치 변경에 활용할 만큼 시간대 변화가 구분되는가 |
| 예측 성능 | 1·3·6시간 후 혼잡도를 기준 모델(또는 서울시 자체 예측)보다 잘 예측하는가 |
| 피크 탐지 | 평소와 다른 인구 증가 시점을 사전에 포착하는가 — **없다는 결과도 유의미한 반증** |
| 행동 가능성 | 예측 시점과 실제 혼잡 시점 사이에 이동 가능한 시간이 있는가 |
| 의사결정 가치 | 결과가 hy 현장실증을 제안할 만큼 구체적인 근거가 되는가 |

### 검토했으나 이번 범위에서 제외한 것: 전자담배 판촉

전자담배(아이코스·릴 등) 판촉 인력을 프레시매니저와 같은 PoC에 포함하는 방안을 검토했으나 **제외 확정**.

| 구분 | 프레시매니저 | 전자담배 판촉 |
|---|---|---|
| 성과지표 | 판매량 | 체험 전환 수·상담 수 |
| 핵심 병목 | 유동인구 예측 | 판촉 가능 장소 자체의 법적 허용 여부 |
| 법적 리스크 | 위치정보법 동의(비교적 단순) | 국민건강증진법 제9조의4 — 담배 광고·판촉 원칙적으로 지정소매인 영업소 내부로 제한, 위반 시 형사처벌 |
| 데이터 정합성 | 담당구역 내 어디든 유효 | 흡연부스 정확한 좌표 필요한데 공공데이터 커버리지가 14/25 자치구뿐 |

**재검토 조건**: 담배 판촉의 실제 법적 근거(지정소매인 영업소 예외 해당 여부, 제조사·유통사 별도 허가 여부)를 법무 검토로 확인하기 전까지 데이터 분석 단계로 넘어가지 않음. 재개 시 활용 가능: 강남구 테헤란로 전자담배 전용 분리형 부스(사실 #6), 강남역=서초구·테헤란로=강남구 관할 분리.

## 7. 다음 세션에서 할 일 (Day 02 — 외부 검토 반영으로 우선순위 변경)

**변경 이유**: 서울시가 이미 12시간 예측(Seq2Seq AI)을 제공한다는 게 확인됐으므로, "우리가 예측 모델을 개발"하는 게 아니라 "서울시 기존 예측이 이 서비스에 쓸 만한지 검증"부터 시작한다. 자체 모델 개발은 이 검증에서 부족함이 확인될 때만 진행.

- [ ] 여의도 관련 정확한 장소명·코드를 실제 API 응답에서 확인(120/121/122 표기 불일치와 무관하게 실호출 기준으로 확정)
- [ ] API 키 발급 후 여의도 실시간 인구 + 서울시 자체 예측값(응답 필드에서 실제로 확인) 동시 수집 시작
- [ ] 오전에 수집한 서울시 예측치(1·3·6시간 후)를 이후 실제 관측값과 비교해 예측오차 측정
- [ ] 서울 실시간 도시데이터의 "여의도" POI 영역과 흡연부스 등 후보 판매지점의 실제 좌표가 겹치는지 확인 (공간 단위가 서로 다름 — 영역 전체 혼잡도를 개별 지점 혼잡도로 오해하지 않도록 주의)
- [ ] 서울시 예측이 부족하다고 판단될 때만 자체 베이스라인 모델(동일 요일·시간 평균 + 날씨 보정) 착수, 서울시 예측을 기준선으로 삼아 비교
- [ ] 출퇴근·점심시간 외 반복적으로 붐비는 시간대가 실제로 존재하는지 확인 — 없다는 결과도 유의미한 결론으로 기록
